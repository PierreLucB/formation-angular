## 📅 Programme

### **Jour 1 : Fondamentaux**
- JavaScript/TypeScript modernes
- Composants, templates, data binding
- Directives, pipes, control flow
- TP : Mini-application interactive

### **Jour 2 : Réactivité & Services**
- RxJS et Observables
- Signals (nouvelle API réactive)
- Services et injection de dépendances
- Formulaires réactifs
- TP : Application multi-composants

### **Jour 3 : Routing & HTTP**
- Router, navigation, guards, lazy loading
- Requêtes HTTP et intercepteurs
- API Resource, SSR et hydration
- TP : Communication avec API REST

### **Jour 4 : Tests & Production**
- Tests unitaires (Jasmine/Vitest)
- Build et optimisation
- Déploiement en production
- TP : Build et mise en ligne

## 🛠️ Installation Requise

**À installer AVANT le Jour 1 :**

```bash
# 1. Node.js (version 20.x ou 22.x)
node --version

# 2. Angular CLI
npm install -g @angular/cli@20

# 3. VS Code avec extensions :
# - Angular Language Service
# - ESLint
# - Prettier
```

**Vérification :**
```bash
node --version    # v20.x.x ou v22.x.x
npm --version     # 9.x.x ou 10.x.x
ng version        # Angular CLI: 20.x.x
```

## 🌟 Nouveautés Angular 20

- **Signals** : Réactivité fine-grained native
- **Mode Zoneless** : +30-50% de performances
- **Standalone Components** : Architecture simplifiée
- **SSR amélioré** : Hydration progressive
- **Tooling moderne** : esbuild et Vite
- **IA intégrée** : Assistance au développement
