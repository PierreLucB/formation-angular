🔤 JAVASCRIPT & TYPESCRIPT
Fonction traditionnelle : 
const obj = {
  nom: 'Alice',
  saluer: function() {
    console.log(this.nom); // Alice
  }
};
obj.saluer(); // Affiche : Alice
Arrow function : 
const obj = {
  nom: 'Bob',
  saluer: () => {
    console.log(this.nom); // undefined
  }
};
obj.saluer(); // Affiche : undefined
La différence :
  • Fonction traditionnelle : this dépend de qui l'appelle
  • Arrow function : this vient du scope parent (lexical)
✅ Important pour Angular : Utilisez les arrow functions dans les callbacks et RxJS.
Un module est simplement un fichier avec import/export : 
// Fichier: math.ts
export function additionner(a, b) {
  return a + b;
}

// Fichier: main.ts
import { additionner } from './math';
console.log(additionner(2, 3)); // 5
C'est juste :
  • Une fonction `export` (exporte depuis ce fichier)
  • Une fonction `import` (importe depuis un autre fichier)
💡 Point clé : Chaque fichier TypeScript est un module. Les imports/exports permettent de réutiliser le code.

Exemple dans un service : 
async chargerUtilisateurs() {
  try {
    const response = await fetch('/api/users');
    const users = await response.json();
    return users;
  } catch (error) {
    console.error(error);
  }

Mais Angular préfère RxJS : 
chargerUtilisateurs() {
  return this.http.get('/api/users').pipe(
    catchError(error => {
      console.error(error);
      return [];
    })
  );
}
⚠️ Important : RxJS est plus puissant qu'async/await pour Angular. On les combine souvent.

🎯 ANGULAR FONDAMENTAUX
[(ngModel)] = Property Binding + Event Binding : 
<input [(ngModel)]="nom" placeholder="Entrez votre nom">
<p>Vous avez saisi : {{ nom }}</p>
Ce qui se passe :
  • Quand vous tapez : la propriété `nom` se met à jour
  • Quand `nom` change : l'input se met à jour
  • Les deux restent synchronisés (two-way)
💡 Syntaxe : [(ngModel)] s'appelle "Banana in a box" (banane dans une boîte) à cause des parenthèses/crochets.
⚠️ Important : Vous devez importer FormsModule pour utiliser ngModel.
Ce sont les nouvelles syntaxes Angular 17+ pour les control flows : 
@if (utilisateur) {
  <p>Bienvenue {{ utilisateur.nom }}</p>
} @else {
  <p>Veuillez vous connecter</p>
}

@for (item of items; track item.id) {
  <li>{{ item.nom }}</li>
}
Avant (ancienne syntaxe) :
  • *ngIf="condition" → @if
  • *ngFor="let item of items" → @for
✅ Moderne et lisible : Les nouvelles syntaxes sont plus claires et performantes. À préférer !
C'est un composant autonome qui ne dépend pas d'un NgModule : 
@Component({
  selector: 'app-salut',
  standalone: true,
  imports: [NgIf, FormsModule],
  template: `...`
})
export class SalutComponent { }
Avant :
  • Fallait créer un NgModule
  • Déclarer les composants dedans
  • Complexe pour les petits projets
Maintenant :
  • standalone: true
  • Déclarer les dépendances dans `imports`
  • Simple et clair
✅ À utiliser toujours : Les composants standalone sont la norme en 2024.
track aide Angular à identifier les éléments pour la performance : 
// SANS track - mauvaise performance
@for (item of items) {
  <li>{{ item.nom }}</li>
}

// AVEC track - bonne performance ✅
@for (item of items; track item.id) {
  <li>{{ item.nom }}</li>
}
Ce qui se passe :
  • Sans track : Angular recréé tous les éléments à chaque changement
  • Avec track : Angular identifie par id et ne recréé que le nécessaire
💡 Règle simple : Utilisez toujours track item.id si l'item a un id unique.
⚠️ Performance : Sans track, une liste de 1000 items devient très lente !
Un pipe transforme les données dans le template : 
<p>{{ nom | uppercase }}</p>
<p>{{ prix | currency }}</p>
<p>{{ date | date:'short' }}</p>
C'est juste une fonction de transformation :
  • | uppercase → convertit en majuscules
  • | lowercase → convertit en minuscules
  • | currency → formate en devise
  • | date → formate la date
✅ Important : Les pipes ne modifient PAS la valeur, juste son affichage.
Avec les composants standalone, vous importez directement ce que vous utilisez : 
// AVANT - avec CommonModule (bloated)
imports: [CommonModule]

// MAINTENANT - importer directement ✅
imports: [NgIf, NgFor, NgClass, FormsModule]
Avantages :
  • Plus léger (tree-shaking)
  • Clair ce qui est utilisé
  • Moderne et recommandé
✅ Nouvelle approche : Importer uniquement ce que vous utilisez, pas toute CommonModule.
